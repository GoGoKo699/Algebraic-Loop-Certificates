# Source-by-source audit: primary splitting is not new orbit machinery

27 September 2026. Research evidence, not manuscript prose. The group lemma and
projector comparison are derived and proved in THEORY.md. We do not attribute
that exact source-certificate interface to a paper that does not state it.

## Direct antecedents and the actual inspection

**Hillar and Rhea, Automorphisms of finite abelian groups.** American Mathematical
Monthly 114(10), 917-923 (2007); preprint math/0605185 (2006).
https://arxiv.org/abs/math/0605185
https://arxiv.org/pdf/math/0605185

Primary parsed text of Theorem 3.3, Lemma 3.4, Theorem 3.6 and proofs was checked.
It gives the mixed-order integer-matrix representation and the modulo-p
criterion for invertibility. This directly supports the algebraic foundation;
it is not evidence that this project invented nonfree module arithmetic.
The screenshot request failed. No chart, table or scan-only measurement is used.

**Banin and Tsaban, The Discrete Logarithm Problem in Bergman's non-representable
ring.** arXiv:1206.1077v2 (2012).
https://arxiv.org/abs/1206.1077
https://arxiv.org/pdf/1206.1077

Primary parsed Sections 2.1-2.3 and the code in Section 3 were inspected. The
Euler isomorphism immediately after Reduction 3 splits the scalar unit group
modulo p^2 into additive p-primary and multiplicative field parts. Reduction 4
uses it for logarithms; Reductions 9-10 handle the mixed-order endomorphism ring.
The paper's target-exponent output is different from source-only membership.
We do not infer that its printed code already implements our full compiler.
It does establish a close primary/field decomposition precedent. Screenshot
requests failed; the algebra above was available as parsed primary text.

**Sutherland, Structure computation and discrete logarithms in finite abelian
p-groups.** Mathematics of Computation 80 (2011), 477-500; arXiv:0809.3413.
https://arxiv.org/abs/0809.3413
https://arxiv.org/pdf/0809.3413

Primary abstract and the general algorithmic setup were inspected. Generic
p-group algorithms are not lower bounds for the explicit coefficient-based
module problem. This audit uses the already-proved structured decoder as a
COMMON primitive and does not claim a new generic logarithm algorithm.

**Viglietta and Kachi, Efficient Lifting of Discrete Logarithms Modulo Prime
Powers.** arXiv:2505.07434v1 (2025 preprint).
https://arxiv.org/html/2505.07434v1

The HTML algorithm specification, comparison with Bach and conclusion were
read. Their input includes a residue logarithm and their output recovers a
lifted exponent. Our membership-only query is weaker; avoiding that input
is not, without a matched contract, an improvement to their exponent algorithm.
The published performance ratios were not adopted or reproduced.

**Menezes and Wu, The Discrete Logarithm Problem in GL(n,q).** Ars Combinatoria
47 (1997), 23-32.
https://combinatorialpress.com/ars-articles/volume-047-ars-articles/the-discrete-logarithm-problem-in-gln-q/
https://combinatorialpress.com/article/ars/Volume%20047/volume_47_paper-3.pdf

The publisher's abstract and PDF metadata were available; the ten-page scan
again supplied no parsed text and the requested page screenshots failed. A
runtime download failed DNS resolution. The complete paper was NOT read this
round. Search for alternative copies did not yield an accessible primary copy.
This known gap is not evidence of novelty. The present narrow conclusion does
not depend on guessing what is on those pages: the explicit group proof and
matched adapter already settle the status of the lifting equivalence itself.

## What the audit does and does not conclude

| Candidate claim | Finding |
|---|---|

| The earlier source-representation theorem is false | Not found; unchanged tests and the replacement logic agree |
| A principal new publication contribution is established | Not yet; do not count a scope extension as novelty clearance |

The next priority is a representation-level comparison: spell out the exact
certificate obligation missing from prior compact character/primary methods,
construct the strongest certifying version of that comparator, and compare
proof size, checking work, supported queries and shared preprocessing. This is
not a request to expand a competitor's polynomials or charge it for target
logarithms it does not need. The prior source-certificate and query-boundary
results remain available as supporting lemmas and implementation infrastructure.
