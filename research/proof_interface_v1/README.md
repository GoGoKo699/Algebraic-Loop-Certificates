# Circuit witnesses through Certifaiger

This research checkpoint connects the original published LFSR safety circuits
to an existing hardware proof interface. The independently supplied model
retains every input, including arbitrary nonzero reseeding. An untrusted
producer adds a history register and emits an ordinary AIGER witness circuit.
ABC's exported invariants provide a second producer at the same interface.

See [CONTRACT.md](CONTRACT.md) for the acceptance boundary,
[THEORY.md](THEORY.md) for the phase and history arguments,
[NATIVE_PROTOCOL.md](NATIVE_PROTOCOL.md) for the frozen cases and limits, and
[SOURCES.md](SOURCES.md) for tool and literature provenance. The project-level
decision is [gate 11](../PROOF_INTERFACE_GATE_11.md).

## Executed native result

All five positive witnesses passed all nine obligations generated by native
Certifaiger. Each obligation was converted to CNF, solved by CaDiCaL, and its
retained LRAT trace checked by native lrat-trim. Four trivial liveness obligations
are included because the pinned checker emits them even for these safety-only
models. No obligation was skipped.

| Candidate | Width | Witness bytes | LRAT bytes, uncompressed | Native pipeline seconds |
|---|---:|---:|---:|---:|
| ABC forbidden cubes | 2 | 833 | 9,695 | 0.102 |
| ABC forbidden cubes | 4 | 12,393 | 367,471 | 0.122 |
| Phase history | 2 | 1,146 | 13,787 | 0.078 |
| Phase history | 4 | 2,802 | 230,169 | 0.103 |
| Phase history | 8 | 11,211 | 25,813,066 | 3.417 |

These are single-run native replay observations, including obligation generation,
conversion, SAT search and native proof checking. They exclude tool builds and
candidate construction; the retained construction records distinguish those
costs. The 11 KB width-8 witness generates about 26 MB of SAT proofs: compact
witness size is not compact proof size. Large evidence files are losslessly
compressed, with hashes for both their stored and uncompressed bytes.

Separate post-replay reconstructions of the phase witnesses took 0.067, 0.037
and 0.172 seconds at widths 2, 4 and 8, including a fresh Python process and
file output. Their bytes exactly match the native inputs. These measurements
were taken later with uncontrolled filesystem caches; original construction
was unmeasured, so they are not one observed end-to-end run.

The earlier fixed PDR run timed out at width 8. The new successful replay is a
concrete integration result at that width; it is not a general PDR limitation,
statistical speedup ratio or measured large-width scaling law.

All four corrupted witnesses were rejected: constant-false witness bad output
fails Safety, a changed original latch reset fails Reset, and frozen/inverted
phase controls fail Inductive. These are bad certificates for safe models;
they are not unsafe-model claims.

## What is independently checked

The ordinary proof identifies both the reachable and universally safe sets.
For nonzero pairs under a primitive update, any original-state safety invariant
must encode canonical phase parity. Shifted parity queries recover the phase
in O(n) queries. This is not an unconditional complexity lower bound. Added
history supplies the phase along executions, so the extended invariant can be
evaluated with polynomially many gates without solving for that phase.

The independent finite checks include:

* Exact forward and backward state sets for all 109 odd-order invertible binary
  matrices in dimensions 1 through 3; 355 singular kernel counterexamples.
* 283 full phase-recovery tests, 9,344 extended-state checks, and 4,084 edges
  preserving the mathematical history predicate.
* 8,704 exhaustive raw-gate state/input transitions at widths 2 and 3, plus
  2,954 width-4/8 controls, checked without symbolic Boolean normalization.
* A strict independent positive-hint LRAT checker for all retained accepted
  CNF proofs. Its false-proof, malformed-input and resource-limit controls
  include fabricated UNSAT proofs for truth-table-confirmed satisfiable CNFs.

The LRAT checker imports neither a solver nor the witness producer. Its
supported subset, propagation argument and limits are documented in
`lrat.py`; unsupported proof rules reject. CNF unsatisfiability is what it
proves. Certifaiger's model/witness obligation construction and AIGER's CNF
translation remain trusted. Hash and log checks preserve the observed native
execution; they do not prove those transformations correct.

## Run without external dependencies

From the repository root:

```sh
python -m research.proof_interface_v1.verify
```

This verifies the checkpoint, runs independent mathematical and raw-gate
controls, and replays the retained CNF proofs with the Python standard library.
It downloads nothing and starts no native solver. The root `python verify.py`
includes it. A candidate can be regenerated separately:

```sh
python -m research.proof_interface_v1.produce \
  --model research/aiger_lfsr_v1/upstream/fibonacci-08-0xb8.aag \
  --taps 0xb8 --output /tmp/lfsr-phase-witness.aag
```

The producer refuses to overwrite the destination. Generating a candidate is
not an acceptance verdict. Native replay requires the separately built tools
and protocol described in the native record.

## Scope

The phase producer supports the preserved wrapper at widths 2 through 24 and
requires exact maximal nonzero period. It deterministically checks point 1's
order using complete trial-division prime factors and exact matrix powers.
Neither upstream expected-result labels nor filenames establish that premise.
The earlier checker required only odd order and remains unchanged. An explicit
identity-map example rejects the temptation to use a nonminimal odd exponent
with this stronger phase predicate.

Conventional primitive-polynomial reasoning can produce the same witness.
Squarefree-polynomial reasoning still solves the weaker odd-order safety
decision. This checkpoint establishes existing-interface feasibility, not an
advantage of the complete orbit engine, a novel proof system, end-to-end formal
verification or scientific completion. Manuscript work remains on hold.
