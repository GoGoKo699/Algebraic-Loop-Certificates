# Modular precision composition (experimental)

The prime field F_(2^w) is not ordinary w-bit wraparound arithmetic. This module
uses actual Z/NZ semantics and constructs derived F_p recurrences one precision
layer at a time. It checks complete point-target hit schedules, including
negative answers, for invertible affine recurrences.

Read [the proof and boundary](THEORY.md) before using the code. This is a research
schema, not a change to the root production API. Manuscript work remains on hold.
A novel publication-level contribution or practical speedup is not established.

From a repository root or the supplied runnable source subset:

```sh
python research/modular_lifting_v1/verify.py
python -O research/modular_lifting_v1/verify.py
```

The tests cover 67,180 small modular cases, with 117,170 field subcertificates,
plus a separate 64-bit wraparound example. The former include all scalar affine
cases for the listed small moduli, all invertible two-by-two matrices modulo4
with two fixed translations and all state/target pairs, and seeded additional
matrices. Examples and exhaustive families may overlap; they are case counts,
not a claim of distinct application problems.

The 64-bit example obtains a known-time full-state hit using64 derived field
certificates. Its compact certificate is21,744 bytes in canonical compact JSON.
It is an easy classical congruential family, not a hard-workload speedup test.
The local proof confirms a period2^64 without enumerating that orbit.

The checker always reconstructs the high-digit recurrence from already checked
lower-precision data. Malformed chains, missing factors, changed source problems,
wrong inverse matrices, noncanonical times and forged outcomes are rejected.
UNKNOWN on producer resource exhaustion is not unreachability.

All code and evidence are new. Original primary code and historical audits remain
unchanged. `expected.json.gz` (gzip-compressed exact JSON) is regenerated by the verifier into temporary storage,
never overwritten to make a mismatch disappear. The producer uses a bounded
reference field solver, not a new fast general order or logarithm algorithm.

For a positive answer, [the direct order witness](../direct_modular_hits_v1/README.md) is substantially simpler than this general precision chain. The old chain fixtures remain unchanged as regression controls. Do not use their size or cost as the strongest positive-certificate baseline.
