# Contribution assessment: a domain extension is not the missing novelty result

27 September 2026. Manuscript writing remains on hold. The primary APIs,
historical evidence, and earlier research proofs are unchanged.

## A concrete comparison is now completed

The [primary-splitting audit](../audits/primary_splitting_v1/README.md) replaces
the prime-power wrapper's target-phase-free step with a standard CRT-projector
construction. It has the same coarse guarantees, needs the same one checked
field source, and performs no target finite-field logarithm. Its correctness
follows from an elementary finite-group lemma with explicit commutation and
p-kernel hypotheses. The tests include a false ambient-order shortcut and
hypothesis counterexamples, not only successful examples.

The comparison is controlled: cyclic-module normalization, the checked residue
compiler and the p-group kernel are shared. This proves that the LIFTING STEP
has an ordinary primary-decomposition explanation. It does not claim that a
retrieved prior package already has the entire field compiler or certificate
contract. A shared component cannot be treated as a competitor independently
reimplementing that same component.

## Revised status of the candidate contributions

| Object | Current assessment |
|---|---|
| Direct positive order certificates | Established mathematics, useful implementation |
| Cyclic module and mixed-order normalization | Standard algebra with implementation obligations |
| Prime-power target-phase removal | Elementary primary-decomposition consequence, now with a matched adapter |
| Complete source-only field representation | Precise proved candidate; representation-level originality comparison still open |
| Independently checked code and explicit failure modes | Valid engineering/evidence; formal verification not performed |
| Partial-target and preprocessing limitations | Supporting scope results with attributed predecessors |
| Native full-matrix performance advantage | Not established |
| Overall scientific readiness | Not complete; no manuscript drafting |

The prime-power extension should remain a supporting corollary and application
of the field/source representation, not be promoted to the main novelty claim.
This is a narrower assessment than declaring the whole programme unpublishable.
The algorithms and proofs remain useful; the comparison directs effort toward
the unresolved component rather than another extension.

## Next task and its required output

Freeze domain/format expansion for the next contribution audit. Put the field
compiler and an equally compact character/primary-decomposition method side by
side under the SAME task: a static untrusted source certificate, deterministic
checking, exact membership for every later complete target, and no hidden
query-phase search. Identify exactly which extra witness or checking obligation
the latter needs, whether a polynomial bound follows from existing methods,
and whether an actual difference in assurance, representation or cost remains.

The deliverable is a checked claim-to-predecessor argument, not another list of
broadly relevant citations. A genuine completeness, verifier-cost or proof-size
result can be the contribution; it need not be a runtime speedup. But a custom
schema, a larger supported modulus or an extensive test count does not by itself
supply one. If the same guarantee follows at comparable cost, classify that part
as an implementation/corollary rather than assuming novelty from missing wording.

No manuscript, release, external contact, paid computation or parent-project
modification is part of this assessment. Repository integration and CI are operational evidence, not
proof of scientific priority.
